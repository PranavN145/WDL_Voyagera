# 🌍 VOYAGERA

## 📖 Short Description
VOYAGERA is a travel website designed for backpackers and explorers who want to discover destinations beyond the typical tourist attractions. The platform offers an interactive world map, destination guides, local experiences, and travel inspiration, making trip planning more engaging and informative.

## ✨ Features
- Interactive world map with continent-based navigation
- Dedicated pages for different countries and destinations
- Destination highlights and travel guides
- Backpacker-focused recommendations
- Responsive and modern user interface
- Interactive cards and smooth navigation
- Team and Contact sections
- Clean, user-friendly design

---

## ⚙️ The Process
1. Designed the website structure and navigation flow.
2. Developed responsive pages using HTML and CSS.
3. Integrated JavaScript for interactivity and dynamic navigation.
4. Created an interactive SVG world map for continent selection.
5. Organized destination information into structured travel guides.
6. Refined the user experience through layout and UI improvements.
